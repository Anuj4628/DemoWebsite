# DemoWebsite

## Redcore Steels — Industrial Demo Website

A high-performance, responsive React + Vite industrial website built for modern steel manufacturing, global supply, and precision engineering client demonstrations.

### Features
- Modern industrial responsive design & animations (GSAP)
- Comprehensive product catalog & material specifications (Stainless Steel, Duplex, Super Duplex, Titanium, Inconel, Monel, Hastelloy)
- Interactive Request-for-Quote (RFQ) workflows & direct contact integration
- Clean component architecture with Vanilla CSS design tokens

### Quickstart
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```
